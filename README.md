# Vowly - Wedding RSVP & Seating Planner

A single-page wedding RSVP dashboard and drag-and-drop seating chart.
Vanilla HTML, CSS and JavaScript - no frameworks, no CDN, no build step.

## Features

- RSVP form with party size, dietary notes and message
- Live counters: replies, attending seats, awaiting seats, seated guests
- Filterable guest list with per-status tags
- Drag-and-drop seating chart: 4 tables x 6 seats, plus an unseated pool
- State persists in localStorage (a demo wedding loads on first visit)

## Run

Open `index.html` in any modern browser, or serve the folder with any static host.
